1. Title of the Project

WeatherGPT: Conversational AI for Weather Forecasting, Alerts, and Climate Information

2. Abstract

Weather information heavily impacts everyday planning, agriculture, and outdoor activities. Conventional weather apps display dense, numerical dashboards that users find difficult to interpret, while general-purpose AI chatbots can explain topics conversationally but hallucinate weather values because they are not connected to real-time telemetry.

WeatherGPT bridges this gap through a decoupled 3-tier microservice architecture uniting two distinct AI paradigms:

  • Generative AI (Google Gemini): Utilized strictly for natural language query comprehension, entity extraction, and conversational explanation—grounded explicitly in live weather data to prevent hallucinations.
  • Custom Machine Learning (Scikit-Learn Microservice): Independently trained on 6 years of daily historical climate observations for Jalandhar, Punjab (2019–2024; 2,184 samples). A chronological train-test split (2019–2023 for training, 2024 for testing) was implemented to prevent temporal data leakage.

Our Temperature Regressor (Linear Regression) achieved an R² Score of 0.9750 (MAE = 1.048°C, RMSE = 1.309°C) on unseen 2024 test data. Our Rainfall Classifier (Logistic Regression with balanced class weights) successfully tackled seasonal class imbalance to achieve 83.56% Accuracy, 0.7115 F1-Score, and an ROC-AUC of 0.8362. The platform is deployed with a Next.js 14 frontend, Express.js API gateway, and Python FastAPI microservice.

3. Problem Statement

  • Data is difficult to interpret: Traditional dashboards show raw atmospheric values (pressure in hPa, dew point) without actionable context.
  • AI Chatbot Hallucinations: General LLMs lack live weather API connectivity and fabricate weather values.
  • Lack of Custom Machine Learning in Consumer Apps: Commercial applications rely on proprietary black boxes without providing transparent model evaluation metrics, confidence intervals, or regional calibration.

5. Dataset & Feature Engineering Pipeline

Historical atmospheric data was collected for Jalandhar, Punjab (Lat: 31.3256° N, Lon: 75.5792° E) from January 1, 2019 to December 31, 2024 (2,184 daily records).

  • Chronological Split (Zero Data Leakage): 2019–2023 was used for Training (1,819 samples), and the full calendar year 2024 was reserved for testing (365 unseen days).
  • Engineered Features: 3-day autoregressive temperature lags (t-1, t-2, t-3), 7-day rolling mean temperatures, humidity/pressure lags, and sine/cosine cyclical day-of-year and month encodings.

Scientific Insight: Linear Regression achieved an outstanding R² of 0.9750, proving that 97.5% of regional temperature variance is successfully explained by autoregressive momentum and cyclical seasonality, with an average error of merely 1.04°C.

6.2 Model B: Rainfall Prediction (Binary Classification)

Target: Predict next-day rainfall occurrence (Rain ≥ 0.1 mm vs. No Rain).

Class Imbalance Treatment: Northern India exhibits extreme seasonal dry spells. In our test year 2024, there were 259 dry days vs. 106 rain days (~71% vs 29%). We integrated class_weight='balanced' to prevent majority-class bias.

Algorithm Accuracy Precision Recall F1-Score ROC-AUC Status
Logistic Regression (Balanced) 83.56% 72.55% 69.81% 0.7115 0.8362 Selected
Random Forest Classifier 80.82% 68.00% 64.15% 0.6602 0.7937 Baseline

  • ROC-AUC Score: 0.8362, indicating strong discriminative capability across all thresholds.

7. Complete Implemented Modules

  1. Live Weather Dashboard: Real-time conditions, 24-hr hourly carousel, 7-day outlook, and Next-Day ML predictions.
  2. ML Model Insights View: Displays live model evaluations, confusion matrix, and prediction probabilities.
  3. Grounded Gemini AI Assistant: Answers user queries conversationally using live Open-Meteo context injection.
  4. Multi-City Comparison: Side-by-side comparison of up to 3 cities simultaneously.
  5. Historical Climate Analytics: Interactive 7, 14, and 30-day time-series charts.
  6. Interactive Satellite Radar Map: OpenStreetMap + Leaflet with real-time RainViewer precipitation satellite radar overlays.

8. Conclusion

WeatherGPT demonstrates that coupling grounded Generative AI with customized Scikit-Learn models provides an accurate, explainable, and accessible weather intelligence tool. By collecting localized historical climate data, avoiding temporal data leakage, and resolving class imbalance, the project satisfies rigorous academic and engineering criteria for B.Tech (AI & ML).
